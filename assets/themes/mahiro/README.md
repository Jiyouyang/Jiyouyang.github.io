## 加载规则

- 仅选中 `mahiro` 时创建两个装饰 `img`，图片不承担导航功能，均带空 `alt` 和 `aria-hidden` 容器。
- 浏览器直接请求上表的国内 CDN，使用 `referrerPolicy="no-referrer"`；不是只把页脚链接写成国内来源。
- CDN 报错或 8 秒无响应时，自动换成本站同源的相同 JPEG；备用图也失败则保留 CSS 奶油粉紫装饰，不显示破图。
- 其他风格初次加载不会请求这些图片，离开该主题后图片与版权说明均隐藏；已请求的图片可能保留浏览器缓存。
- 原始 CDN 已从当前执行环境完成下载校验；`tests/mahiro-art.cjs --live` 已在浏览器中确认两个实际远程 URL 加载成功、没有进入本地回退。测试浏览器显式信任当前托管环境代理 CA 的 SPKI（环境变量 `CHROMIUM_TRUSTED_SPKI`），没有全局关闭证书验证。此环境不是中国大陆网络探针，不保证各地区/运营商或外链源未来始终可用；本地备用图用于降低该风险。
